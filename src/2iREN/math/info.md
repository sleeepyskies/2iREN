# Info

## Conventions

This details the math conventions of 2iREN.

### Coordinate System

2iREN follows a left handed coordinate system. This means we have the
following unit vectors:

- _UP_ := `(0, 1, 0)`
- _DOWN_ := `(0, -1, 0)`
- _LEFT_ := `(-1, 0, 0)`
- _RIGHT_ := `(1, -1, 0)`
- _FORWARD_ := `(0, 0, 1)`
- _FORWARD_ := `(0, 0, -1)`
